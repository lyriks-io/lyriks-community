# Support

- **A bug or a feature idea**: open an issue with the matching template. Say
  which version you run (Settings > Versions) and how you installed it.
- **A question about using Lyriks**: the in-app feedback dialog reaches the
  team directly, and feedback@lyriks.io works too.
- **A security concern**: never in a public issue; see [SECURITY.md](SECURITY.md).
- **The appliance**: `./lyriks smoke` tells you whether an install can be
  used, `./lyriks logs <service>` shows what a service says, and
  `./lyriks doctor` checks a host before installing.
